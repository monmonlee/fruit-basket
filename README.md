# 水果籃運動週卡

每週重訓加有氧的打卡小 app，目標由每個人自己訂。每打卡一次，籃子裡就多一顆水果。

- 每週目標：第一次打開會有 3 步驟設定（玩法介紹 → 選部位、有氧次數、週期功能 → 範本或空白菜單），籃子格數與分數依目標而定；之後可在「每週目標」修改
- 籃子就是按鈕：還沒摘的水果以半透明影子浮在籃子上方，點一下就從下方滑出記錄面板；籃子裡的水果點了可以修改
- 同一套流程：① 出門前（打算去 → 出門了，自動算拖了多久，並填預估痛苦）② 內容（重訓依水果種在葡萄架／草莓田／西瓜田／桃樹上：每個動作一排、每一組一顆果實，每組可各自設定次數與重量，完成就採收成當天的水果；有氧是暖身／有氧／收操清單）③ 練完（實際痛苦＋打卡）。痛苦分數是可選功能（「每週目標」裡開關，新使用者預設關閉）：大腦常高估運動有多累（Ruby 等人，2011），出門前先猜、練完再打分，就知道腦袋多想了幾分
- 月曆：一眼看出這個月練了哪些部位
- 預估 vs 實際痛苦分數：看看出門前的腦袋多想了幾分
- 今天真的很不想運動：籃子下方的入口。四關決策樹（身體警報 → 電量：睡眠／經期／肚子 → 時間 → 累的真相與心情），最後「登、登、登、登……」揭曉 8 種結局之一；每個建議都標明是「📚 研究指出」還是「💡 一般建議」
- 三個分頁：週卡（每天看的）、月曆、設定（每週目標、菜單、備份、外觀）
- 果醬櫃：月曆頁每個月一罐果醬，顏色是那個月練最多的、高度是完成幾成；新月份會提醒上個月的果醬熬好了
- 特效與音效：採收閃光、水果掉進籃子、整籃裝滿灑水果；音效以程式合成，可在外觀區關閉；尊重「減少動態效果」
- 外觀：跟隨手機／淺色／深色，在 app 最下方切換
- 菜單會學習：練完打卡時，如果這次和固定菜單不同，會問要不要把新增／沒做的動作更新進菜單；新的一週每個動作自動帶入上次同一動作的次數與重量
- 打卡日期：打卡時可選今天／昨天／這週的某一天，已打卡的也能改日期
- 備份提醒：超過 14 天沒備份（或用了 3 天還沒備份過），首頁會提醒
- 有氧越努力水果越大：可記距離與時間（自動算配速），依距離（或時間）摘到 🫐 藍莓 → 🍎 蘋果 → 🍍 鳳梨 → 🍈 哈密瓜，面板上有果實階梯提示「再 X 公里升級」；有氧名稱可在設定改成「跑步」等
- 額外運動：記錄類型、分鐘、一句話備註，每一筆抵一次運動，放一顆 🍒 櫻桃
- 月經週期（四季分法）：按「月經今天來了／結束了」，自動推算冬（月經期）、春（濾泡期）、夏（排卵期）、秋（黃體期），並給對應的運動建議；經期可選 🍑 經期日，練輕的就好

## 怎麼用

用手機打開網址，**第一次就先加到主畫面**，之後都從圖示打開：

- iPhone：Safari →「分享」→「加入主畫面」
- Android：Chrome → 選單 →「加到主畫面」

資料存在自己手機的瀏覽器裡，每個人各自一份。從主畫面圖示和從 Safari 分頁打開的資料是分開的。換手機或清除瀏覽器資料前，記得用「匯出備份」。

## 發佈新版

```
scripts/release.sh "這次改了什麼"
```

會更新版本號、commit 並 push。打開中的 app 回到前景時會比對 `version.json`，發現新版就在下方顯示「有新版本，點我更新」。
